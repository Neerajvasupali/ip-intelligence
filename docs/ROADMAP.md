# Roadmap

The active development scope is the [15-task event-investigation release](TASK_STATUS.md). External alerting integrations are outside the current scope.

The release candidate implements bounded JSON intake, deduplication, fixed-window correlation, queue reuse, contextual priority and event-aware reports. Remaining release gates are deployment approval, authenticated browser verification and a human manual-versus-assisted evaluation. Future work includes direct case navigation, measured throughput optimization and independent security review. No automatic blocking is planned for this release.
