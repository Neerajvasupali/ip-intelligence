# Manual-versus-assisted evaluation

No participant results have been collected. The CSV is a blank collection template, not a performance claim.

Use the same labeled scenarios and fixed intelligence evidence in both methods. A manual trial uses the event file and separate source-evidence documents; an assisted trial uses the investigation report. Agree on the required output: event count, activity window, asset, provider disagreement/freshness, disposition and explanation. A participant should not be rewarded for closing an uncertain case as malicious.

Record participant experience, trial order, any prior exposure to a case, provider mode and interruptions. Counterbalance case/method order or use matched scenarios to reduce learning effects. Start timing when the case and resources become available; end when the required decision and explanation are recorded. Record active hands-on time separately from wall-clock waiting. Include failed/incomplete attempts rather than silently discarding them.

Summarize per-case observations, participant count, median time and spread. Report paired differences only for comparable trials. Describe the small-sample and synthetic-data limitations. External API requests and exact-replay behavior can be measured automatically, but they do not substitute for human investigation-time measurements. Do not present synthetic scenario agreement as real-world detection accuracy.
